# Chinmaya Kumar Mishra – Personal Portfolio

> **Full-Stack Developer | Application Security Enthusiast**  
> Building Applications. Understanding Security.

Personal portfolio website built with modern JavaScript, Next.js (App Router), React 19, Tailwind CSS, and Framer Motion. Showcases full-stack software development experience across the MERN stack alongside active learning and practical exploration in Application Security (AppSec).

---

## 🚀 Technology Stack

- **Framework:** [Next.js 15](https://nextjs.org/) (App Router, JavaScript)
- **Library:** [React 19](https://react.dev/)
- **Styling:** [Tailwind CSS 3](https://tailwindcss.com/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)

---

## 🛠️ Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Locally in Development Mode
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
npm start
```

---

## ✏️ Updating Content

All text, links, project details, and experience information are centralized in:
```
data/portfolioData.js
```
To update your profile, simply edit that single file—all sections, cards, and modals will reflect the updates automatically.
